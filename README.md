### What I work on

**Vendor-agnostic agentic-dev tooling.** [ai-skills](https://github.com/alex-voloshin-dev/ai-skills)
is a working playbook of patterns that survived production use across
Claude Code, Codex, and Windsurf. It ships 26 agents, 77 skills, 48
eval rubrics with 288 calibration samples, and a tracked parity
matrix.

**Three angles I keep returning to:**

- **Tri-vendor parity** — most agentic-dev expertise is locked into
  one runtime; the cross-vendor view is rare and useful
- **Eval rubrics with real calibration data** — "is the agent
  working?" deserves a better answer than vibes
- **Formal-methods × agentic dev** — LTL, model checking, and FRR
  apply to agent specifications more directly than people think
